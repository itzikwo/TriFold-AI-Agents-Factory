# Clients

One directory per client, named by slug: `clients/<client-slug>/`.

```
clients/<client-slug>/
  CLAUDE.md          — filled instance
  PROFILE.md          — filled instance
  BOUNDARIES.md       — filled instance
  STATE.md            — skeleton only, never synced after go-live
  setup-report.md
```

See `registry.md` for the client ↔ template version table, and Section 8 of the PRD for the full artifact layout.
